## Что сделано

- отдельный репозиторий на базе КР №1
- `css/responsive.css` + Mobile First медиазапросы
- viewport на всех страницах
- мобильное меню
- skip-link, подписи полей, alt у картинок
- адаптив каталога, формы и таблицы
